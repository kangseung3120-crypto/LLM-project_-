
# Local LLM vs Cloud API 비교 (STEP 7)

**중요**: 로컬은 질문당 **2회 반복**, Cloud는 질문당 **1회**만 실행했습니다. 반복 수가 다르므로
품질·속도를 1:1로 단순 비교하지 말고, 이 차이를 항상 함께 언급합니다.
비교 대상 질문은 5개(Q1, Q3, Q5, Q7, Q9) — STEP5에서 결과를 보기 전에 미리 선정한 것입니다.

## Quality (실측, 동일 5개 질문 Q1/Q3/Q5/Q7/Q9 기준)

| 모델 | 정확성 | 핵심정보누락 | 지시형식준수 | 한국어표현 | 정보부족시대응 |
|---|---|---|---|---|---|
| qwen2.5:7b (n=10, 질문당 2회) | 4.6 | 3.8 | 4.0 | 5.0 | 5.0 (n=2) |
| exaone3.5:7.8b (n=10, 질문당 2회) | 4.3 | 4.0 | 4.0 | 4.8 | 5.0 (n=2) |
| gpt-5.6-luna (n=5, 질문당 1회) | **5.0** | **4.6** | **4.8** | 5.0 | 5.0 (n=1) |

**Luna가 5개 기준 중 4개에서 로컬 두 모델을 앞섰습니다.** 특히 Q5(추미애 청원 기사)에서 로컬 모델들이 대부분 "논조 차이 없음"이라고 뭉뚱그린 반면, Luna는 두 기사의 실제 강조점 차이(리더십 위기 프레이밍 vs 절차·양측입장 병렬제시)를 정확히 짚어냈습니다.
단, Cloud는 반복이 1회뿐이라 n이 작고, 재현성(동일 입력 반복 시 결론 일관성)은 이번 실험에서 측정하지 못했습니다.

## Latency (실측, 동일 5개 질문 기준)

| 모델 | 평균 응답시간 | 비고 |
|---|---|---|
| qwen2.5:7b | 4.21초 (n=10) | 로컬, 네트워크 없음 |
| exaone3.5:7.8b | 5.36초 (n=10) | 로컬, 네트워크 없음 |
| gpt-5.6-luna | 4.83초 (n=5) | **네트워크 왕복 포함**임에도 Qwen과 비슷하고 EXAONE보다 빠름 |

## Cost

| 모델 | 비용 |
|---|---|
| qwen2.5:7b / exaone3.5:7.8b | 장비 이미 보유, 한계비용 0에 가까움 (전력비만) |
| gpt-5.6-luna | 5회 호출 합계 **추정 $0.003593** (약 5원 수준) — platform.openai.com/usage에서 실제 청구액과 반드시 대조할 것 |

## Security

| 모델 | 내용 |
|---|---|
| qwen2.5:7b / exaone3.5:7.8b | 기사 원문이 로컬 PC를 벗어나지 않음 — 데이터 완전 통제 가능 |
| gpt-5.6-luna | 기사 원문이 OpenAI 서버로 전송됨 — 개인정보·민감정보가 포함된 기사라면 외부 전송 리스크 고려 필요 (이번 실험은 공개 뉴스 기사 + 합성 데이터만 사용해 문제 없음) |

## Infrastructure / Operations

| 모델 | 내용 |
|---|---|
| qwen2.5:7b / exaone3.5:7.8b | Ollama 설치, 모델 다운로드, GPU/드라이버 관리 필요. 서빙 인프라를 직접 운영해야 함 |
| gpt-5.6-luna | API 키 발급만으로 즉시 사용 가능, 서버 운영 부담 없음. 다만 OpenAI 서비스 가용성에 의존 |

## Customization

| 모델 | 내용 |
|---|---|
| qwen2.5:7b / exaone3.5:7.8b | 오픈소스라 파인튜닝·내부망 구성·모델 교체 자유로움. Qwen은 Apache 2.0이라 상업적 커스터마이징도 가능 |
| gpt-5.6-luna | OpenAI가 제공하는 API 범위 내에서만 사용 가능, 모델 자체 수정 불가 |

## 실측 결과 vs 운영 조건 분석 (구분해서 기록)

**실측 결과** (이번 실험에서 직접 측정한 것):
- 품질 점수 (5개 질문 x 모델 3개)
- 응답 시간
- 입력/출력 토큰 수, 추정 비용

**운영 조건 분석** (실측이 아니라 서비스 요구사항에 따른 추론):
- 보안 요구 수준에 따라 Cloud 전송 가능 여부가 달라짐 (이번 실험 데이터는 공개·합성이라 문제없지만, 실제 서비스에서 민감 기사를 다룬다면 판단이 달라질 수 있음)
- 인프라 운영 인력·예산이 없으면 Cloud API가 현실적일 수 있음 (이는 측정값이 아니라 판단)
