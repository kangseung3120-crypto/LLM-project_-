## 3. 대표 성공 사례
- **모델**: exaone3.5:7.8b / **질문ID**: Q4
- **왜 대표적인지**: 두 기사가 표면적으로는 비슷해 보이지만("차이없음"이라 답하기 쉬운 함정), 실제로는 기사1(구체적 실행계획 중심)과 기사2(시민 영향·노사협상 강조) 사이에 실제 강조점 차이가 있었고, EXAONE이 이를 두 번 다 일관되게(rep1, rep2 모두) 정확히 짚어냄.
- **근거가 되는 응답 부분**: "기사 1은 서울시의 구체적인 대응 방안과 실행 계획에 더 중점을 둔다... 기사 2는 파업의 영향과... 교통 소외지역 주민 및 이동약자의 불편을 강조하며..."

## 4. 대표 실패 사례
- **모델**: exaone3.5:7.8b / **질문ID**: Q9 (rep2)
- **어떤 기준에서 왜 감점됐는지**: 정확성·지시형식준수. 본문에서는 두 기사의 차이점을 구체적으로 설명해놓고, 최종 결론에서 "논조 차이 없음"이라고 스스로의 분석과 모순되는 결론을 내림. 같은 입력을 rep1에서는 "논조 차이 있음"으로 답해 재현성도 깨짐.
- **근거가 되는 응답 부분**: "...세부 강조점의 차이가 존재한다. **논조 차이 없음** (큰 틀에서는 유사하나 세부 강조점의 차이가 존재)" — 결론 문구 자체가 자기모순.

## 추가로 중요한 발견 (원래 채점 기준엔 없지만 보고서에 넣을 가치가 있음)

**재현성(reproducibility) 이슈**: temperature=0으로 고정했음에도, EXAONE은 Q3·Q5·Q9에서 rep1과 rep2의 "논조 차이 유무" 결론이 서로 달랐습니다(10개 질문 중 3개, 30%). Qwen은 10개 질문 전부 rep1·rep2 결론이 일치했습니다. 애초에 "재현성"이 강승규님 프로젝트의 핵심 요구사항이었던 걸 감안하면, 이 결과는 **Qwen이 EXAONE보다 재현성 측면에서 더 안정적**이라는 걸 보여주는 유의미한 데이터입니다. (참고: Ollama의 temperature=0도 GPU 부동소수점 연산 특성상 100% 결정론적이진 않다는 점은 감안해야 합니다.)
