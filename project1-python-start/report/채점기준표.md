# 채점 기준표 (모델 x 질문 x 반복 회차별 작성, 1~5점 + 근거 서술)

각 응답마다 아래 5개 기준으로 점수를 매기고, 반드시 **점수 근거를 한 줄씩 적습니다** (왜 3점인지 등).

## 1. 정확성
기사 내용과 사실관계가 일치하는가. 지어낸 내용(hallucination)이 없는가.
- 5점: 기사 내용과 완전히 일치, 지어낸 내용 없음
- 3점: 대체로 일치하나 사소한 과장/확대해석 있음
- 1점: 기사에 없는 내용을 사실처럼 서술함
- **점수 근거 예시**: "기사에 없는 'oo부 관계자 발언'을 언급함 → 1점"

## 2. 핵심정보 누락
기사의 핵심 내용을 빠짐없이 담았는가.
- 5점: 핵심 정보 누락 없음
- 3점: 부차적인 정보는 빠졌지만 핵심은 담음
- 1점: 핵심 정보(주제, 결론 등)가 빠짐
- **점수 근거 예시**: "기사의 핵심 수치(oo%)를 언급하지 않음 → 3점"

## 3. 지시·형식 준수
요청한 답변 구조("핵심 사실 요약 + 논조 차이" 또는 질문이 요구한 형식)를 지키는가.
- 5점: 요구 구조를 정확히 지킴
- 3점: 구조는 있으나 순서가 다르거나 일부 누락
- 1점: 구조 지시를 무시하고 자유 형식으로 답함
- **점수 근거 예시**: "논조 차이 항목을 아예 언급하지 않고 요약만 함 → 3점"

## 4. 한국어 표현
문장이 자연스러운가, 번역투나 비문이 없는가.
- 5점: 자연스러운 한국어
- 3점: 이해되지만 다소 어색함
- 1점: 부자연스럽거나 비문이 많음
- **점수 근거 예시**: "'~에 대해 대한 논의가' 같은 중복 표현 발견 → 3점"

## 5. 정보부족 시 대응
기사에 없는 정보를 물었을 때(Q7, Q8 등) 어떻게 대응하는가. **정보부족·범위밖 사례가 아닌 질문에는 해당 없음(N/A)으로 표기.**
- 5점: "기사에 해당 정보 없음"을 명확히 밝히고 지어내지 않음
- 3점: 없다고는 했지만 애매하게 얼버무리거나 일부 추측을 섞음
- 1점: 없는 정보를 있는 것처럼 답함
- **점수 근거 예시**: "수치가 없는데도 '약 30% 수준으로 추정된다'고 지어냄 → 1점"
