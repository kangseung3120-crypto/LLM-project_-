# 뉴스 요약 QA 프로젝트

여러 뉴스 매체의 기사를 비교하여 **핵심 내용을 요약하고, 기사 간 공통점과 차이점을 분석하는 QA 프로젝트**입니다.

## 1. 프로젝트 목표

매일/매주 여러 뉴스 기사를 직접 비교해야 하는 상황에서,

* 기사의 핵심 사실을 간결하게 요약
* 여러 기사의 공통점과 차이점 비교
* 한국어 뉴스에 적합한 로컬 LLM 선정


### 중요도

**한국어 성능 > 응답속도 > 데이터 보안**

---

## 2. 개발 환경

| 항목             | 내용               |
| -------------- | ---------------- |
| Language       | 한국어              |
| Task           | 뉴스 요약 + 기사 비교 QA |
| 입력             | 기사 2개 + 질문 직접 입력 |
| 검색             | 자동 검색 없음         |
| GPU            | VRAM 8GB         |
| Driver         | 592.01           |
| 실행 환경          | Ollama           |
| 모델 크기          | 5~6GB 이하         |
| Context Length | 32K              |


---

## 3. 비교 모델

* **Qwen2.5:7B**   (https://huggingface.co/Qwen/Qwen2.5-7B-Instruct)
* **EXAONE3.5:7.8B** (https://huggingface.co/LGAI-EXAONE/EXAONE-3.5-7.8B-Instruct-AWQ)

---

## 4. 실행 성능 비교

본 실험은 워밍업 실행을 제외하고 각 모델 **20회씩** 측정했습니다.

| 지표       |   Qwen2.5:7B | EXAONE3.5:7.8B | 결과           |
| -------- | -----------: | -------------: | ------------ |
| 성공률      |        20/20 |          20/20 | 동일           |
| 평균 응답 시간 |    **4.12초** |          5.02초 | **Qwen 우세**  |
| 생성 속도    |   63.1 tok/s | **65.2 tok/s** | EXAONE 근소 우세 |
| 평균 VRAM  | **4528 MiB** |       4945 MiB | **Qwen 우세**  |
| 워밍업 로딩   |       3.664초 |         3.329초 | EXAONE 근소 우세 |

---

## 5. QA 품질 비교

* **EXAONE**: 정확성, 핵심정보, 지시 형식에서 근소하게 우세
* **Qwen**: 한국어 표현에서 근소하게 우세
* 두 모델 모두 **40/40 호출 성공**

같은 질문을 2회 반복하여 응답의 일관성을 확인했습니다.

* **Qwen**: 10개 질문 모두 결론 일치
* **EXAONE**: Q3, Q5, Q9에서 결론이 변경됨

→ **재현성 측면에서는 Qwen이 더 안정적인 결과를 보였습니다.**

## 8. 최종 결론

현재 실험 결과를 종합하면:

**프로젝트 기본 모델 → Qwen2.5:7B**

선정 이유:

1. 한국어 표현 점수가 높음
2. 평균 응답 시간이 약 **18% 빠름**
3. VRAM 사용량이 약 **400MiB 적음**
4. 반복 실험에서 더 안정적인 재현성을 보임
5. 8GB VRAM 환경에서 안정적으로 실행 가능
