## STEP 7. Embedding 실험 결과

### 1. 실험 조건

| 항목     | 설정                                                            |
| ------ | ------------------------------------------------------------- |
| 임베딩 모델 | `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` |
| 문장 수   | 3개                                                            |
| 임베딩 차원 | 384                                                           |
| 비교 방법  | Cosine Similarity                                             |
| 평가 목적  | 문장 간 의미적 유사도 비교                                               |

### 2. 임베딩 변환 결과

| 항목           | 결과         |
| ------------ | ---------- |
| 입력 문장 수      | 3개         |
| 임베딩 결과 Shape | `(3, 384)` |
| 문장 1 벡터      | 384차원      |
| 문장 2 벡터      | 384차원      |
| 문장 3 벡터      | 384차원      |

각 문장을 임베딩 모델에 입력하여 **384차원의 벡터**로 변환하였다.

```text
문장
 ↓
Embedding Model
 ↓
384차원 Embedding Vector
 ↓
Cosine Similarity
 ↓
문장 간 의미적 유사도 비교
```

### 3. Cosine Similarity 결과

| 문장 A             | 문장 B             | Cosine Similarity | 해석         |
| ---------------- | ---------------- | ----------------: | ---------- |
| 고양이가 소파 위에 있다    | 소파 위에 고양이가 앉아 있다 |        **0.9466** | 의미가 매우 유사  |
| 고양이가 소파 위에 있다    | 오늘 주식시장이 상승했다    |        **0.0628** | 의미가 거의 다름  |
| 소파 위에 고양이가 앉아 있다 | 오늘 주식시장이 상승했다    |        **0.1974** | 의미 유사도가 낮음 |

### 4. 자기 자신과의 유사도

| 문장               | 자기 자신과의 Cosine Similarity |
| ---------------- | ------------------------: |
| 고양이가 소파 위에 있다    |                 1.0000002 |
| 소파 위에 고양이가 앉아 있다 |                 1.0000000 |
| 오늘 주식시장이 상승했다    |                 1.0000001 |

> 자기 자신과 비교한 값은 부동소수점 계산 오차로 인해 1보다 아주 조금 크게 나타날 수 있지만, 실질적으로는 1로 볼 수 있다.

### 5. 결과 해석

`고양이가 소파 위에 있다`와 `소파 위에 고양이가 앉아 있다`는 표현과 단어 순서가 다르지만 **0.9466의 높은 Cosine Similarity**를 보였다. 두 문장이 비슷한 의미를 가지고 있기 때문에 높은 유사도가 나타난 것으로 볼 수 있다.

반면 `고양이가 소파 위에 있다`와 `오늘 주식시장이 상승했다`는 **0.0628**로 낮은 유사도를 보였다. 두 문장의 주제와 의미가 서로 다르기 때문에 상대적으로 낮은 값이 나온 것으로 해석할 수 있다.

이를 통해 문장을 임베딩 벡터로 변환하면 단순한 문자열 비교가 아니라 **문장 간 의미적 유사도를 수치로 비교**할 수 있음을 확인하였다.

### 6. 실험 결과 요약

| 관찰 항목        | 결과                                                  |
| ------------ | --------------------------------------------------- |
| 임베딩 차원       | 384차원                                               |
| 유사한 문장       | 0.9466으로 높은 유사도                                     |
| 서로 다른 주제의 문장 | 0.0628로 낮은 유사도                                      |
| 임베딩 활용       | 문장 간 의미적 유사도 비교 가능                                  |
| 한계점          | Cosine Similarity가 높다고 해서 문장의 사실 여부를 판단할 수 있는 것은 아님 |

> **결론:** 이번 실험에서는 문장을 384차원의 임베딩 벡터로 변환한 뒤 Cosine Similarity를 계산하여 문장 간 의미적 유사도를 비교하였다. 표현이 다른 두 문장도 의미가 유사하면 높은 유사도(0.9466)를 보였으며, 서로 다른 주제의 문장은 낮은 유사도(0.0628)를 보였다. 이를 통해 임베딩을 이용한 의미 기반 문장 비교 과정을 확인하였다.
