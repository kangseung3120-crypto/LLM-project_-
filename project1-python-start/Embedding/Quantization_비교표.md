### 5. 실험 결과 요약

동일한 질문과 `temperature=0` 조건에서 Q4_K_M과 Q6_K를 비교하였다. Q4_K_M은 약 5.0GB, Q6_K는 약 6.7GB로 Q4_K_M의 모델 파일 크기가 더 작았다.

생성 속도는 Q4_K_M이 **24.69 tokens/sec**, Q6_K가 **16.66 tokens/sec**로 측정되어 이번 실험에서는 Q4_K_M이 더 빠른 결과를 보였다.

반면 5개 질문에 대한 품질 평가에서는 두 모델 모두 **47/50점**으로 동일했다. 따라서 이번 실험에서는 Q4_K_M과 Q6_K 사이에 뚜렷한 품질 차이는 확인되지 않았다.

또한 두 모델 모두 약 8GB VRAM 환경에서 CPU/GPU 분할 실행되었으며, Q4_K_M은 **46% CPU / 54% GPU**, Q6_K는 **54% CPU / 46% GPU**로 확인되었다. 따라서 생성 속도의 차이를 양자화 수준의 차이만으로 단정하지 않고, CPU/GPU 오프로딩 비율의 차이도 함께 고려하였다.

> **결론:** 이번 실험에서는 Q4_K_M이 Q6_K보다 모델 크기가 작고 생성 속도가 빠르게 측정되었으며, 5개 질문에 대한 품질 평가에서는 두 모델의 차이가 나타나지 않았다. 다만 CPU/GPU 분할 실행 상태가 서로 달랐기 때문에 속도 차이를 양자화 효과만으로 판단하지 않았다.
